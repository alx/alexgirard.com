Module de formation

M3 — Pipeline autonome : ralph, beads & sous-agents

Reproduire un pipeline de développement assisté par agents : boucle autonome, base d'issues, sous-agents qui se contrôlent.

Durée : 2 jours (12 h)

  • Objectifs : comprendre et reproduire un pipeline de développement assisté par agents : une base d’issues (beads) comme source de vérité, une boucle itérative qui travaille seule (ralph), et des sous-agents spécialisés qui se contrôlent mutuellement (worker, tester, reviewer, vérificateur indépendant).
  • Public : développeurs, DevOps, data engineers, tech leads.
  • Pré-requis : confort avec le terminal, git, et un langage de script (Python) ; avoir suivi M2 (fortement recommandé).
  • Contenu ancré dans du réel : démontage d’un run nocturne non supervisé (sélection automatique des tâches, ~5 h d’exécution, rapport de fin de nuit) et d’un harness multi-sous-agents avec vérification croisée inter-modèles.
  • Livrables / résultats mesurables :
    • le participant a fait tourner sa propre boucle autonome sur un petit dépôt (10+ itérations, zéro intervention) ;
    • sa base d’issues est initialisée et synchronisée (2+ issues closes en fin de stage) ;
    • document « règles de l’agent » (ce qu’il peut / ne peut pas faire seul — p. ex. jamais de commit/push sans validation humaine).
